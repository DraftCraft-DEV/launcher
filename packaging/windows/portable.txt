D.E.V. Launcher portable mode

While this file sits next to dev-launcher.exe, D.E.V. Launcher keeps its settings, its
download cache and its record of installed apps in the DevLauncherData folder beside it, and
writes nothing to %APPDATA%. Copy the whole folder to move D.E.V. Launcher with its settings.

Delete this file to use the normal per-user settings folder (%APPDATA%\D.E.V. Launcher) instead.
If DevLauncherData can't be written (for example on a read-only drive), D.E.V. Launcher says
so and uses %APPDATA%\D.E.V. Launcher instead.
